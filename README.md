# Amal's Games

A browser-game portal containing:

## Featured
- Brawl Stars (`bravol-stars/`)
- Blockbust (`blockbust/`)

## Also available
- Zombie vs Plants
- Snake — Arcade Edition
- Pixel Terrarium

The website is designed for static hosting on GitHub Pages.

Open `games/index.html` or serve the `games` folder locally.
