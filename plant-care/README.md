# Цветы — уход за растениями (PWA)

Веб-приложение для iPhone (Safari → «На экран Домой»): коллекция цветов, полив, подкормка, пересадка, климат/сезон и ссылки на покупку удобрений.

## Возможности

- Добавление растения по фото (Plant.id API-ключ в настройках) или вручную из каталога
- Статусы полива / подкормки / пересадки
- Экран «Сегодня» с отметками ухода
- Погода через Open-Meteo и сезонные советы
- Рекомендации удобрений, грунта и горшков со ссылками на Wildberries, Ozon и Яндекс Маркет

## Разработка

```bash
cd plant-care
npm install
npm run dev
```

Сборка статики (база `/plant-care/` для GitHub Pages):

```bash
npm run build
```

Готовые файлы — в `plant-care/dist/` (закоммичены для GitHub Pages). Открывать: `plant-care/dist/`.

## iPhone

1. Откройте приложение в Safari  
2. Поделиться → На экран «Домой»  
3. Запускайте как обычное приложение  

Позже можно обернуть тот же фронт в Capacitor на Mac и выложить в App Store.
